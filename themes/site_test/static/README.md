# 🛍️ Mantu — E-Commerce Web Template

A clean, responsive e-commerce front-end template built with HTML, CSS, and Bootstrap 5. Mantu is designed to mimic a WooCommerce-style shopping experience with a modern UI.

---

## 📄 Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with hero section and featured products |
| Shop | `shop.html` | Product listing/browse page |
| Product Detail | `Product1.html` | Individual product page |
| Cart | `cart.html` | Shopping cart page |
| Checkout | `checkout.html` | Checkout form page |
| Login | `login.html` | User login page |
| Thank You | `thankyou.html` | Order confirmation page |

---

## 🚀 Tech Stack

- **HTML5** — Page structure
- **CSS3** — Custom styling (`style.css`)
- **Bootstrap 5.3** — Responsive layout and components
- **Font Awesome 6** — Icons
- **Bootstrap Icons** — Additional icon set
- **Google Fonts (Poppins)** — Typography

## 🛠️ Getting Started

1. Clone the repository:
   ```bash
     git clone https://github.com/smamanoor79-stack/Mantu---ecommerce.git
   ```

2. Open `index.html` in your browser — no build tools or dependencies required.

---

## 📌 Notes

- This is a **front-end only** template (no backend/database).
- Images should be placed in an `/images` folder in the root directory.
- Designed to be integrated with a CMS or back-end like WordPress/WooCommerce.
